## 🌟 About the Project

**THE VERITY** is a restaurant reservation web application designed to make booking a unique dining experience simple and interactive.

Customers can enter their booking details, explore dining themes, specify dietary preferences, select cuisines, and personalize their experience with optional add-ons and services.

## 🚀 Features

- 📝 **Reservation Form** — Collects customer and booking details.
- 👥 **Dynamic Guest Details** — Adds guest information fields using JavaScript.
- 🥗 **Dietary Preferences** — Captures dietary requirements and allergies.
- 🏛️ **Themed Dining** — Offers public dining themes and private dome options.
- 🍜 **Cuisine Selection** — Allows customers to select their preferred cuisines.
- 🎂 **Custom Add-ons** — Supports cake, beverage, gift, photoshoot, and soundtrack requests.
- 🎉 **Dining Packages** — Provides themed packages for special occasions.
- 🏊 **Additional Services** — Includes optional services such as pool access.
- 🔗 **Backend Integration** — Uses Flask to process reservation form submissions.
- 🗄️ **MySQL Database** — Connects the application to a relational database.

## ⚙️ Getting Started

### Prerequisites

- 🐍 Python installed
- 🗄️ MySQL Server installed and running
- 🌐 A web browser

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/PriyankaPooladasulu/The-Verity.git
cd The-Verity
```

**2. Install the dependencies**

Install Flask and the MySQL connector used by your application:

```bash
pip install flask mysql-connector-python
```

**3. Configure the database**

- Create the `the_verity` database in MySQL.
- Create the required tables.
- Configure your database connection using your local credentials.
- Never commit passwords or secret configuration files to GitHub.

**4. Run the application**

```bash
python app.py
```

Open the local address shown in your terminal, typically `http://127.0.0.1:5000/`, if that is the address configured by your Flask application.

## 🧪 Database Testing

The repository includes `test_db.py`, which can be used to test database connectivity.

Run it with:

```bash
python test_db.py
```

Make sure your MySQL server and local database configuration are ready first.
